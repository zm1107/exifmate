「支持 MP4、MOV、MKV 等主流视频格式的拍摄时间与元数据修改，让你的影视素材库井井有条。」

04

全智能 · 元数据自动流转

「文件名、Exif、修改日期，三个方向自动接力。」

批量识别文件名回写缺失的拍摄时间；把 Exif 拍摄时间同步成文件修改日期；再按 Exif 与修改日期批量重命名。占位符模板（{Y4}{M2}{D2}_{h}{m}{s}）自定义规则，多模板按序匹配，素材库无需手动整理、自动归位。

卖点之外，细节也做满

常规格式与 RAW 全覆盖：JPEG / PNG / GIF / BMP / TIFF / WebP / HEIC，CR2 / CR3 / NEF / ARW / RAF / DNG 等主流相机 RAW，以及 MP4 / MOV / MKV 等主流视频。

分组树形展示全部元数据；RAW 内嵌 JPEG 预览、视频内嵌播放；文件名识别值与现有 EXIF 差异高亮。

改得很快

文件夹递归导入、全流程多线程并行写入；拍摄时间偏移 / 精确设置，相机、镜头、GPS、版权批量修改。
