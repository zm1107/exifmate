# 决策记录：官网宣传重心调整 —— 四大核心卖点置顶

- 日期：2026-09-07

- 影响文件：`index.html`、`en/index.html`、`assets/style.css`

## 背景

旧版首页以「痛点场景」作为叙事开头，隐私、视频格式、撤销、智能识别等核心能力分散在痛点卡片与功能网格中，卖点不够直接。

## 决策

调整为「卖点先行」结构，四大核心卖点按以下优先级置顶展示（中英文页一致）：

1. **全离线 · 真正的隐私架构**：零联网、零账号注册、零数据上报。「你的照片和视频元数据，100% 只属于你的本地硬盘。」——第一主打，视觉上做全宽深色横幅。
2. **全格式 · 不只是照片**：支持 MP4、MOV、MKV 等主流视频格式的拍摄时间与元数据修改，让影视素材库井井有条。
3. **无忧撤销（Panic-Free Batch Editing）**：内置数据库快照，再复杂的批量修改也可一键「还原」回原始状态。
4. **全智能**：批量识别文件名 → 回写 Exif 拍摄时间；Exif 拍摄时间 → 同步文件修改日期；Exif + 修改日期 → 批量重命名。三个方向自动流转。

## 结构变更

旧：Hero → 痛点 → 功能 → 版本对比
新：Hero（隐私主导语）→ 四大核心卖点（图形化）→ 更多能力（原功能网格收敛为非卖点项）→ 典型场景（原痛点区后置）→ 版本对比
